## Compilacion

Para compilar el programa se debe abrir una terminal en la carpeta raiz del proyecto y ejecutar:

```cmd
g++ src\*.cpp -Iinclude -o taller.exe
```

## Ejecucion

Una vez compilado, ejecutar:

```cmd
.\taller.exe
```

**NOTA:** El archivo de pacientes utilizado por el programa se encuentra en:

```text
data/pacientes.txt
```

Si se desea agregar casos de prueba o modificar los datos de entrada, se debe editar dicho archivo.
